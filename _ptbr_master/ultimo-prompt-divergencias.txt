Tarefa para cada arquivo acima:
 1. Leia o Master e a versao Steam.
 2. Decida o cenario:
    (a) Refactor de namespace (orfas = novas, mesma quantidade, mesmo
        texto ingles) -> mapeie nossas traducoes para as novas chaves.
    (b) Strings novas que o autor adicionou -> mantenha o resto e gere
        esqueleto (msgstr = msgid em ingles) para essas, listando
        para tradutor humano/IA depois.
    (c) msgid mudou -> reavalie a traducao existente.
    (d) Misto -> aplique (a)+(b)+(c) conforme cada entrada.
 3. Atualize APENAS o arquivo Master. Nao toque no Steam.
 4. No final, rode novamente aplicar-traducoes.ps1 (pelo atalho ou
    pwsh -File ...) para empurrar o Master atualizado pro Steam.
 5. Se gerou esqueletos novos, atualize a lista em
    mods\_ptbr_master\PROMPT-PARA-IA-TRADUTORA.md com a contagem.

Cuidado conhecido (caso Ronivans): NAO use .po de outro idioma como
base para preencher msgstr; traduza sempre a partir do msgid em ingles.
Em arquivos .po as aspas vem escapadas (\"); ao validar links/tags,
desescape antes do regex.
